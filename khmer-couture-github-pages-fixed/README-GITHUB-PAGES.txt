KHMER COUTURE — GITHUB PAGES

1. Extract this ZIP.
2. Upload the extracted contents to the ROOT of a PUBLIC GitHub repository. At the root, keep index.html, booking.html, contact.html, .nojekyll, and the assets folder together. Do not upload the ZIP itself or put everything inside another folder.
3. Commit the upload to the main branch.
4. Open Settings > Pages. Under Build and deployment, select Deploy from a branch, then choose main and /(root). Save.
5. Wait for the live website URL to appear in Settings > Pages.

This is a static website; it needs no build command. The booking selection is stored in the visitor's browser and is not automatically sent to Telegram.

KHMER COUTURE — GITHUB PAGES PACKAGE

The ZIP is a package of website files. Extract it before publishing; do not upload the ZIP itself as the website.

PUBLISH STEPS
1. Extract this ZIP on your computer.
2. Open your GitHub repository and upload the extracted CONTENTS to the repository root. The root must contain index.html, booking.html, contact.html, and the assets folder.
3. Commit the uploaded files to your main branch.
4. In GitHub, open repository Settings > Pages.
5. Under Build and deployment, select Deploy from a branch. Choose main and /(root), then Save.
6. Wait for the published address shown on that Pages settings screen.

The website is static and needs no build command or server. Keep the assets folder beside the HTML pages so photos and the logo load. Booking details remain in the visitor's browser and are shared only when the visitor chooses a contact channel.
